# 📊 InsightGrid - Smart Excel Dashboard

An automated web tool that transforms raw Excel files into interactive, visual dashboards in seconds.

## 🚀 Live Demo
🔗 **[Try it here!](https://3694abd5c548bbc6b2.gradio.live)**

## ✨ Features
- Upload any `.xlsx` file and get instant insights
- Automatic generation of interactive charts (Plotly)
- Clean data tables with sorting
- Statistical summaries (mean, median, std dev)

## 🛠️ Tech Stack
- **Python** (Pandas for data processing)
- **Gradio** (Web interface)
- **Plotly** (Interactive visualizations)
- **OpenPyXL** (Excel file handling)

## 📦 How to Run Locally
1. Clone this repository: `git clone https://github.com/adilsdk01/insightgrid.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python insight_grid.py`
